# User Story Mapping Workshop

**Type:** Interactive
**Source:** [deanpeters/Product-Manager-Skills](https://github.com/deanpeters/Product-Manager-Skills/blob/main/skills/user-story-mapping-workshop/SKILL.md)

---

## Purpose

Guided workshop to build a two-dimensional user story map. Rather than a flat backlog, produces a map organised by user workflow (horizontal) and priority (vertical), plus walking skeleton and release slices.

**Use for:** New products or major features, transitioning flat backlogs to visual formats, stakeholder alignment on scope, MVP and incremental release planning.

**Not for:** Single-feature projects, well-understood prioritised backlogs, technical refactoring without user workflows.

---

## Five-Question Flow

**Q1: Define Scope** — Entire product / major feature / user journey / redesign?

**Q2: Identify Users** — Single persona / multiple shared workflows / distinct workflows / organisational roles?

**Q3: Generate Backbone** — 5–8 activities forming the narrative flow (horizontal axis)

**Q4: Generate Tasks** — 3–5 user tasks per activity, vertically prioritised (must-have at top)

**Q5: Identify Release Slices** — Walking skeleton (MVP) + enhancement increments

---

## The Walking Skeleton

Highest-priority tasks across *all* activities deliver minimal end-to-end functionality — not completing one feature before starting another. The skeleton reveals gaps between features early.

---

## Output

Structured markdown with:
- Backbone activities across the top
- Full story map with tasks organised by activity
- Three release slices with specific story assignments
- Next steps for refinement and stakeholder validation

---

## Common Pitfalls

- Flat backlog disguised as a map — vertical lists without horizontal narrative
- Technical architecture as backbone — mapping layers (front-end, API, DB) instead of user workflows
- Feature-complete waterfall — building one activity fully before starting others
- Detail overload — mapping every edge case prematurely
- Hidden documentation — maps confined to tools rather than displayed visibly
