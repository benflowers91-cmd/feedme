# Customer Journey Mapping Workshop

**Type:** Interactive
**Source:** [deanpeters/Product-Manager-Skills](https://github.com/deanpeters/Product-Manager-Skills/blob/main/skills/customer-journey-mapping-workshop/SKILL.md)

---

## Purpose

Guided 5-step workshop to build a customer journey map collaboratively. Uncovers end-to-end customer experiences, identifies pain points, and aligns teams around the customer perspective — not internal processes.

---

## Five-Step Flow

**Step 0: Gather Context**
Provide customer research (interviews, support tickets, churn data), product context, and any existing documentation.

**Q1: Identify Actor (Persona)**
Choose: primary persona / secondary persona / high-churn segment / newly discovered segment.

**Q2: Define Scenario + Goal**
Choose: first-time use / core workflow / problem resolution / upgrade or expansion.

**Q3: Identify Journey Phases**
Agent generates 4–6 phases (e.g. Discover → Evaluate → Try → Activate → Use → Expand). Approve or modify.

**Q4: Map Actions, Thoughts, Emotions per Phase**
Agent populates 3–5 per phase. Approve or modify.

**Q5: Identify Opportunities**
Agent generates 5–7 prioritised opportunities (pain points ranked by impact), each with evidence, proposed solution, and HIGH/MEDIUM/LOW impact.

---

## Output

- Complete journey map organised by phase
- Prioritised opportunity list tied to specific phases
- Next-step recommendations for validation, prioritisation, problem framing, and solution design

---

## Common Failures

- Mapping internal sales processes instead of customer experience
- Listing actions without emotions or pain points
- Including too many personas in a single map
- Generating unranked opportunity lists
- Creating maps in isolation without cross-functional input
