# Changelog

### Shopping list

## Previous releases

### PWA / install
- Added service worker and app icons so FeedMe can be installed to the home screen on iOS and Android.

### Recipe search — "Use what I have"
- New toggle on the Find page that builds a recipe search from your safe/moderate pantry ingredients automatically — no manual typing required. While the toggle is on the text input is disabled.
- Search results show which of your pantry ingredients appear in each recipe title or snippet, with a count badge and individual ingredient chips.
- "Sort by pantry match" button reorders results by how many pantry ingredients they mention.
- Pantry ingredient queries are generated by Claude Haiku to produce realistic recipe-shaped search terms rather than raw ingredient names.

### Saved recipes — auto-tagging
- "Auto-tag all" button on the Saved page classifies untagged recipes by meal type (breakfast / lunch / dinner / snack), cuisine, and effort level (quick / moderate / involved) using Claude Haiku. Tags become filterable immediately after tagging.

### Adapt page fixes
- False "Saved" confirmation fixed — the success state is now only set when the API call actually succeeds; a red error message is shown on failure.
- "Method" section relabelled "Original recipe" to reflect that it shows the raw input text rather than Claude-extracted cooking steps.
- Adapt route switched to Claude Haiku with `max_tokens` reduced from 3000 to 2000 for faster responses; `instructions` removed from the tool schema (filled client-side from the original text).

### Pantry search
- Clear (`×`) button added to the pantry search bar on the Find page, visible whenever the input is non-empty.
